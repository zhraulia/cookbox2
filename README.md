# CookBox

CookBox is a Flutter app for browsing local sellers' menu and ingredient
packages. It keeps the following features:

- Login with a phone number and password.
- Browse menus and ingredient packages, including their seller and category.
- Search and filter menus by category.
- View menu ingredients, recipes, and cooking time.
- Save and remove favorite menus from the catalog or detail screen.

## Run

```sh
flutter pub get
flutter run
```

## Test

```sh
flutter test
flutter analyze lib test
```
